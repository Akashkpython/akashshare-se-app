AKASH SHARE - README
====================

Welcome to Akash Share v1.0.5!

INSTALLATION COMPLETE
---------------------
Your Akash Share application has been successfully installed on your system.

WHAT'S INCLUDED
---------------
- Akash Share Desktop Application
- Backend Server (Node.js/Express)
- WebSocket Chat System
- File Sharing Capabilities
- MongoDB Atlas Integration

QUICK START
-----------
1. Launch Akash Share from your desktop or start menu
2. The application will automatically start the backend server
3. Navigate to "Bca Group Chat" to test the chat functionality
4. Use "Send Files" and "Receive Files" for file sharing

FEATURES
--------
✅ Real-time Group Chat with WebSocket
✅ Secure File Sharing
✅ Cross-platform Compatibility
✅ Auto-update System
✅ Modern UI with Dark/Light Themes
✅ Performance Monitoring
✅ Enterprise-grade Security

SYSTEM REQUIREMENTS
-------------------
- Windows 10/11 (64-bit)
- 4GB RAM minimum
- 500MB free disk space
- Internet connection (for MongoDB Atlas)

TROUBLESHOOTING
---------------
If you encounter any issues:

1. Check Windows Firewall settings
2. Ensure port 5002 is not blocked
3. Restart the application
4. Check the logs in: %APPDATA%\AkashShare\logs

UNINSTALLATION
--------------
To uninstall Akash Share:
1. Go to Control Panel > Programs > Uninstall a program
2. Find "Akash Share" and click Uninstall
3. Follow the uninstaller prompts
