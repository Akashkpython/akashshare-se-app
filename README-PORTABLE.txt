# Akash Share - Portable Package 
 
## How to use this portable package 
 
1. Extract this ZIP file to any location on your computer 
2. Install Node.js if not already installed (https://nodejs.org/) 
3. Double-click "AkashShare.bat" to start the application 
 
## Notes 
- This is a development version that requires Node.js to run 
- For best performance, use the installed version when available
