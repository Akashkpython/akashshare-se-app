# Akash Share - Portable Version 
 
## How to use this portable version 
 
1. Extract this folder to any location on your computer 
2. Double-click "Launch-AkashShare.bat" to start the application 
3. The application will run directly without installation 
 
## Notes 
- This is a portable version that does not require installation 
- All application data will be stored in the application folder 
- To uninstall, simply delete the folder
