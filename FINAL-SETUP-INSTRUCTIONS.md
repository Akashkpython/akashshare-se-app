### Available Installation Options:

#### Option 1: Complete Portable Package
- **File**: `AkashShare-Portable.zip` 
- **Use case**: Quick installation, no admin rights needed
- **Instructions**: 
  1. Extract the ZIP file on your target PC
  2. Double-click `Start-AkashShare.bat`
  3. Install Node.js if prompted

#### Option 2: Professional Installer
- **File**: `AkashShare-Final-Installer.bat`
- **Use case**: Proper Windows installation with shortcuts
- **Instructions**:
  1. Copy both `AkashShare-Final-Installer.bat` and `AkashShare-Portable` folder to target PC
  2. Right-click `AkashShare-Final-Installer.bat` → "Run as administrator"
  3. Follow the installation wizard

- **Node.js missing**: Download from https://nodejs.org/
- **Firewall issues**: Allow the application through Windows Firewall
- **Port conflicts**: The app uses ports 5002 (frontend) and 5002 (backend)
